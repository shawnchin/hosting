Jitsi Bookmarklets

Brighten videos

For details, see Community Post: more vivid colors at the meeting

How do I use this?

  1. Drag the following to your bookmark bar → Jitsi-brighten-videos
  2. Whenever you're in a meeting and want to brighten all videos, just click that bookmark item.
  3. Yes, that's it.

What does that script do? It runs the following javascript to inject inline CSS that styles all video elements on the page. 


var s = document.createElement('style')
s.innerText = "video { filter: brightness(1.15) contrast(1.06) saturate(1.12);} ";
document.head.appendChild(s)
